# Portfólio — Paulo Silva

Engenheiro de Dados com foco em pipelines de ingestão e transformação, processamento distribuído e disponibilização de dados para análises. Experiência prática com Python, SQL, PySpark, Databricks, Delta Lake e ferramentas de visualização.

## Projetos em destaque

### 1. Engenharia de Dados e Analytics

- **[Project_finance_pucrs](https://github.com/PauloSilvaSH/Project_finance_pucrs)** — pipeline de dados de ações da B3 com ingestão, camadas Bronze/Prata, atributos analíticos, comparação de modelos de regressão e arquivo de Power BI.
- **[Gastos-Governo](https://github.com/PauloSilvaSH/Gastos-Governo)** — ingestão de dados públicos, transformação com PySpark, persistência Delta e agregação SQL para consumo.

### 2. Coleta, preparação e análise

- **[Coleta-e-prepara-o-de-dados](https://github.com/PauloSilvaSH/Coleta-e-prepara-o-de-dados)** — API Flask, integração de dados de países/PIB e análise exploratória de pesquisas anuais sobre saúde mental no trabalho.
- **[Estatistica_PUC](https://github.com/PauloSilvaSH/Estatistica_PUC)** — estatística descritiva e inferencial, probabilidades, testes de hipótese e regressão linear com dados de futebol.
- **[Programa-para-dados](https://github.com/PauloSilvaSH/Programa-para-dados)** — análise exploratória de jogos da Steam, notas, preços, datas de lançamento e compatibilidade com sistemas operacionais.
- **[Atividade-Universidade](https://github.com/PauloSilvaSH/Atividade-Universidade)** — exercícios de Python e análise de dados meteorológicos.

## Stack identificada nos projetos

- **Linguagens e consultas:** Python, SQL
- **Engenharia de dados:** PySpark, Spark SQL, Delta Lake, ETL
- **Plataformas e dados:** Databricks, CSV, APIs REST
- **Análise e visualização:** Pandas, NumPy, Matplotlib, Seaborn, Power BI
- **Machine Learning:** scikit-learn, XGBoost, regressão linear, Random Forest

> As tecnologias acima foram identificadas nos arquivos dos projetos. A lista não significa que todas as ferramentas sejam usadas em todos os repositórios nem que todos os fluxos tenham sido executados integralmente em ambiente limpo.

## Como navegar neste portfólio

Cada repositório possui um README com objetivo, arquivos principais, tecnologias, etapas observadas no código, orientações gerais de reprodução e oportunidades de melhoria. Consulte o README específico antes de executar um projeto, pois alguns dependem de arquivos locais, serviços externos ou configuração de Databricks.
